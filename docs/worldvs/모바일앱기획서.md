아래는 **AI 코딩 에이전트에게 그대로 전달해서 Android 앱 개발을 시작할 수 있는 수준**의 앱 개발 기획서입니다.
전제는 **1차 MVP는 백엔드 없이 Android 앱 단독 배포**, 데이터는 앱 내부 JSON으로 포함하거나 빌드 시 갱신하는 방식입니다.

# 앱 개발 기획서

## 국가 비교 시각화 & 퀴즈 앱

## 1. 앱 개요

### 앱 가칭

**World VS / 국가 VS / 나라대결**

### 한 줄 설명

두 나라를 좌우로 놓고 인구, 경제, 군사, 생활, 문화, 환경 지표를 **게이지와 카드로 직관적으로 비교**하고, 비교 데이터를 바탕으로 **퀴즈까지 즐기는 국가 비교 앱**.

### 핵심 콘셉트

사용자가 앱을 열면 화면이 좌우로 나뉘어 있다.

왼쪽에는 한국, 오른쪽에는 일본 같은 식으로 두 나라가 표시된다.

각 나라에는 국기, 국가명, 대표 수치가 표시되고, 아래에는 비교 항목들이 카드 형태로 이어진다.

예:

```text
🇰🇷 대한민국        🇯🇵 일본

인구
5,170만 명         1억 2,300만 명
██████░░░░         ██████████

GDP
1.7조 달러         4.2조 달러
████░░░░░░         ██████████

전투기 수
400대              200대
████████░░         ████░░░░░░
```

사용자는 왼쪽 또는 오른쪽 국가를 즉석에서 바꿔보며 국가 간 차이를 감각적으로 확인할 수 있다.

## 2. MVP 목표

### MVP의 목표

1. 두 나라를 좌우 비교한다.
2. 국가 선택을 빠르게 바꿀 수 있다.
3. 비교 항목은 20개 내외로 제한한다.
4. 비교 항목마다 게이지, 수치, 짧은 해설을 제공한다.
5. 동일 데이터를 이용해 퀴즈 화면을 제공한다.
6. 백엔드 없이 앱 내부 JSON 데이터로 동작한다.
7. Android Kotlin 기반으로 개발한다.

### MVP에서 하지 않는 것

초기 버전에서는 아래 기능을 제외한다.

1. 회원가입
2. 로그인
3. 서버 DB
4. 관리자 페이지
5. 실시간 데이터 자동 갱신
6. 유료 결제
7. 사용자 랭킹 서버 저장
8. 소셜 공유 이미지 서버 생성

## 3. 추천 기술 스택

### Android

```text
Language: Kotlin
UI: Jetpack Compose
Architecture: MVVM
State: ViewModel + StateFlow
Local Data: JSON asset file
Local Storage: DataStore
Charts/Gauge: Compose Canvas 또는 커스텀 Progress Bar
Min SDK: 26 이상
```

### 백엔드

MVP에서는 사용하지 않는다.

향후 확장 시:

```text
Supabase:
- country_data 테이블
- quiz_questions 테이블
- user_score 테이블
- remote config 역할

Vercel:
- 데이터 갱신용 API
- 관리자용 웹 대시보드
```

## 4. 데이터 전략

### 4.1 MVP 데이터 방식

백엔드 없이 배포하기 위해 앱 내부에 다음 파일을 포함한다.

```text
app/src/main/assets/countries.json
app/src/main/assets/indicators.json
app/src/main/assets/country_indicator_values.json
app/src/main/assets/quiz_templates.json
```

앱은 실행 시 asset JSON을 읽어 화면에 표시한다.

데이터 갱신은 앱 업데이트로 처리한다.

### 4.2 데이터 출처 후보

MVP에서 가장 안정적인 출처는 다음과 같다.

| 데이터 종류                  | 추천 출처             | 비고                                                                           |
| ----------------------- | ----------------- | ---------------------------------------------------------------------------- |
| 국가명, 국기, 수도, 지역, 언어, 통화 | REST Countries    | 250개 이상 국가 정보와 국기, 언어, 통화 등 제공 ([REST Countries][1])                         |
| 인구, GDP, 면적, 기대수명 등     | World Bank WDI    | World Bank의 World Development Indicators는 공식 국제 출처 기반의 개발 지표 모음 ([데이터뱅크][2]) |
| 사회/환경/교육/보건 지표          | Our World in Data | Grapher API와 데이터 카탈로그를 통해 국가별 지표 접근 가능 ([docs.owid.io][3])                   |
| 군사력, 항공기 수 등            | Global Firepower  | 군사력 비교와 항공 전력 등 지표 제공. 단, 라이선스와 정확성 주의 필요 ([Global Firepower][4])            |

### 4.3 군사 데이터 주의

군사력 데이터는 재미 요소로는 좋지만, 공식 통계가 아니거나 추정치가 많다.
따라서 앱 내에서는 다음과 같이 표시하는 것이 좋다.

```text
군사 지표는 공개 자료 기반 추정치이며 실제 전력과 다를 수 있습니다.
```

또한 “전쟁 승패 예측”처럼 민감하게 보일 수 있는 표현은 피하고, “공개 지표 비교”로 제한한다.

## 6.2 국가 선택 방식

사용자의 아이디어를 반영해 **좌우 슬라이드 국가 선택 패널**을 구현한다.

### 왼쪽 국가 변경

왼쪽 끝에서 오른쪽으로 스와이프하면 왼쪽 국가 선택 패널이 열린다.

```text
← 왼쪽 패널

🇰🇷 대한민국
🇯🇵 일본
🇺🇸 미국
🇨🇳 중국
🇩🇪 독일
🇫🇷 프랑스
🇬🇧 영국
🇮🇳 인도
```

### 오른쪽 국가 변경

오른쪽 끝에서 왼쪽으로 스와이프하면 오른쪽 국가 선택 패널이 열린다.

### 검색 기능

국가가 많아지면 검색이 필요하다.

```text
국가 검색: "일본", "Japan", "JP"
```

### 즐겨찾기

MVP에서는 선택사항이지만 구현하면 좋다.

```text
자주 비교하는 국가:
🇰🇷 한국
🇯🇵 일본
🇺🇸 미국
🇨🇳 중국
```

## 7. 비교 게이지 설계

## 7.1 기본 게이지 계산

두 나라의 값 중 큰 값을 100으로 보고 작은 값을 비율로 표시한다.

예:

```text
한국 인구: 51,700,000
일본 인구: 123,000,000

한국 게이지 = 51,700,000 / 123,000,000 * 100 = 42
일본 게이지 = 100
```

## 7.2 낮을수록 좋은 지표

일부 지표는 낮을수록 긍정적일 수 있다.

예:

```text
CO₂ 배출량
실업률
물가상승률
범죄율
```

MVP에서는 혼란을 줄이기 위해 낮을수록 좋은 지표는 별도 라벨을 붙인다.

```text
이 항목은 낮을수록 좋은 지표입니다.
```

## 7.3 비교 문장 자동 생성

각 카드 하단에 짧은 문장을 생성한다.

예:

```text
일본이 한국보다 약 2.4배 많아요.
한국이 일본보다 약 18% 높아요.
두 나라가 거의 비슷해요.
데이터가 부족해 비교할 수 없어요.
```

### 비교 문장 규칙

```kotlin
if valueA == null || valueB == null:
    "데이터가 부족해 비교할 수 없어요."
else if ratio >= 2.0:
    "{winner}이/가 {loser}보다 약 {ratio}배 높아요."
else if ratio >= 1.15:
    "{winner}이/가 {loser}보다 약 {percent}% 높아요."
else:
    "두 나라가 거의 비슷해요."
```

## 8. 재미 요소 추가 아이디어

## 8.1 나라 성향 배지

```text
🇯🇵 일본

🎬 콘텐츠 강국
⚔ 방위력 집중 국가
```

배지는 정량 데이터 기반으로 부여한다.

예:

```text

기대수명 82세 이상 → 👴 장수 국가

```

## 14.1 게이지 계산

```kotlin
class GaugeCalculator {

    fun calculate(left: Double?, right: Double?): Pair<Float, Float> {
        if (left == null || right == null) {
            return 0f to 0f
        }

        if (left <= 0.0 && right <= 0.0) {
            return 0f to 0f
        }

        val max = maxOf(left, right)

        return ((left / max) * 100).toFloat() to
               ((right / max) * 100).toFloat()
    }
}
```

## 14.2 비교 문장 생성

```kotlin
class CompareSummaryGenerator {

    fun generate(
        leftCountryName: String,
        rightCountryName: String,
        leftValue: Double?,
        rightValue: Double?,
        unit: String
    ): String {
        if (leftValue == null || rightValue == null) {
            return "데이터가 부족해 비교할 수 없어요."
        }

        if (leftValue == 0.0 && rightValue == 0.0) {
            return "두 나라 모두 값이 0입니다."
        }

        val biggerName: String
        val smallerName: String
        val biggerValue: Double
        val smallerValue: Double

        if (leftValue >= rightValue) {
            biggerName = leftCountryName
            smallerName = rightCountryName
            biggerValue = leftValue
            smallerValue = rightValue
        } else {
            biggerName = rightCountryName
            smallerName = leftCountryName
            biggerValue = rightValue
            smallerValue = leftValue
        }

        if (smallerValue == 0.0) {
            return "$biggerName 쪽 값이 더 높습니다."
        }

        val ratio = biggerValue / smallerValue

        return when {
            ratio >= 2.0 -> "$biggerName이/가 $smallerName보다 약 %.1f배 높아요.".format(ratio)
            ratio >= 1.15 -> "$biggerName이/가 $smallerName보다 약 %.0f%% 높아요.".format((ratio - 1.0) * 100)
            else -> "두 나라가 거의 비슷해요."
        }
    }
}
```

```text
- 오른쪽 국가 영역을 누르면 오른쪽 국가 선택 화면을 연다.
- 선택한 국가는 DataStore에 저장하여 다음 실행 때 유지한다.

앱 구조:
```

## 등록 허용

익명 앱에서 insert를 허용할 수 있지만, 악의적 등록을 막기 어렵습니다.
MVP에서는 아래 정도로 제한합니다.

```sql
CREATE POLICY "Allow public leaderboard insert"
ON leaderboard
FOR INSERT
WITH CHECK (
    score >= 0
    AND score <= 100
    AND correct_count >= 0
    AND correct_count <= total_questions
    AND total_questions = 10
    AND duration_seconds > 0
    AND duration_seconds <= 3600
    AND char_length(player_name) >= 2
    AND char_length(player_name) <= 20
);
```

## 주의

앱에 Supabase anon key가 들어가므로, 완벽한 치팅 방지는 어렵습니다.

MVP에서는 다음 정도만 적용합니다.

```text
1. score는 0~100만 허용
2. total_questions는 10으로 고정
3. duration_seconds는 1~3600초만 허용
4. 이름 길이 제한
5. 동일 device_id_hash의 과도한 등록 제한은 추후 Edge Function에서 처리
```

# 20. Java용 핵심 클래스 예시

## 20.1 GaugeCalculator.java

```java
public class GaugeCalculator {

    public GaugePair calculate(Double leftValue, Double rightValue) {

        if (leftValue == null || rightValue == null) {
            return new GaugePair(0f, 0f);
        }

        if (leftValue <= 0 && rightValue <= 0) {
            return new GaugePair(0f, 0f);
        }

        double max = Math.max(leftValue, rightValue);

        float leftGauge = (float) ((leftValue / max) * 100.0);
        float rightGauge = (float) ((rightValue / max) * 100.0);

        return new GaugePair(leftGauge, rightGauge);
    }
}
```

## GaugePair.java

```java
public class GaugePair {

    private final float leftGauge;
    private final float rightGauge;

    public GaugePair(float leftGauge, float rightGauge) {
        this.leftGauge = leftGauge;
        this.rightGauge = rightGauge;
    }

    public float getLeftGauge() {
        return leftGauge;
    }

    public float getRightGauge() {
        return rightGauge;
    }
}
```

## 20.2 LeaderboardEligibilityChecker.java

```java
import java.util.List;

public class LeaderboardEligibilityChecker {

    public boolean isEligible(int userScore, int durationSeconds, List<LeaderboardEntry> top100) {

        if (top100 == null || top100.size() < 100) {
            return true;
        }

        LeaderboardEntry lastEntry = top100.get(top100.size() - 1);

        if (userScore > lastEntry.getScore()) {
            return true;
        }

        if (userScore == lastEntry.getScore()
                && durationSeconds < lastEntry.getDurationSeconds()) {
            return true;
        }

        return false;
    }
}
```

```java
import java.util.List;

public class QuizScoringService {

    public QuizScore calculateScore(List<QuizAnswer> answers) {

        int totalQuestions = answers.size();
        int correctCount = 0;

        for (QuizAnswer answer : answers) {
            if (answer.isCorrect()) {
                correctCount++;
            }
        }

        int score = 0;

        if (totalQuestions > 0) {
            score = (int) Math.round((correctCount * 100.0) / totalQuestions);
        }

        return new QuizScore(score, correctCount, totalQuestions);
    }
}
```
