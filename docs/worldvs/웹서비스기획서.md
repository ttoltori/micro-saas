# World VS — 웹서비스 기획서

> 본 기획서는 `모바일앱기획서.md`의 World VS 콘셉트를 `AGENTS.md` 아키텍처 원칙에 맞춰 웹서비스로 재설계한 문서다. AI 코딩 에이전트가 이 문서만으로 개발에 착수할 수 있도록 작성되었다.

---

## 1. 서비스 개요

### 서비스명

**World VS**

### 한 줄 설명

두 나라를 좌우로 놓고 인구, 경제, 군사, 생활, 문화, 환경 지표를 게이지와 카드로 직관적으로 비교하고, 비교 데이터를 바탕으로 퀴즈를 풀며 세계 상식을 테스트하는 국가 비교 웹서비스.

### 핵심 가치

- **비교 감각**: 단순 정보 나열이 아닌, 두 국가를 나란히 놓고 차이를 체감
- **학습과 재미의 결합**: 비교 데이터 기반 퀴즈로 자연스러운 학습 유도
- **공유와 발견**: 비교 결과를 URL로 공유하고, 다른 사람의 비교를 발견
- **접근성**: 설치 없이 웹에서 바로 사용, 모바일 웹도 반응형 지원

### 웹 서비스만의 차별 포인트

| 기능 | 설명 |
|---|---|
| **공유 가능한 비교 URL** | `worldvs.com/compare/KR-vs-JP` 형태의 URL로 비교 결과 공유 |
| **동적 OG 이미지 생성** | 소셜 미디어 공유 시 비교 결과 카드 이미지 자동 생성 |
| **SEO 최적화** | 국가 상세 페이지, 비교 페이지 SSR/SSG로 검색 유입 확보 |
| **트렌딩 비교** | 가장 많이 비교된 국가 조합 TOP 10 노출 |
| **퀴즈 결과 공유** | 퀴즈 완료 후 고유 URL 발급, 결과 카드 이미지 공유 |
| **PWA 지원** | 홈 화면 추가 시 앱처럼 동작, 오프라인 비교 화면 사용 가능 |
| **임베드 위젯** | 외부 사이트에 비교 카드를 iframe으로 삽입 가능 (Phase 2) |

## 2. MVP 목표

### MVP 목표

1. 두 나라를 좌우 비교하는 화면을 웹에서 제공한다.
2. 국가 선택을 빠르게 바꿀 수 있다.
3. 비조 항목은 20개 내외로 제한한다.
4. 비교 항목마다 게이지, 수치, 짧은 해설을 제공한다.
5. 동일 데이터를 이용해 퀴즈를 제공한다.
6. 퀴즈 10문항 완료 후 점수를 산출하고 리더보드에 등록할 수 있다.
7. 비교 결과와 퀴즈 결과를 URL로 공유할 수 있다.
8. 반응형 웹으로 모바일/태블릿/데스크톱을 지원한다.

### MVP에서 하지 않는 것

1. 회원가입 / 로그인 (익명 사용자 기반)
2. 관리자 페이지
3. 실시간 데이터 자동 갱신
4. 유료 결제
5. 소셜 로그인
6. 사용자 생성 콘텐츠 (댓글, 게시판)
7. 임베드 위젯
8. 다국어 (MVP는 한국어 우선, 구조만 다국어 대비)

### 6.6 오류 응답

```json
{
  "success": false,
  "error": {
    "code": "COUNTRY_NOT_FOUND",
    "message": "국가를 찾을 수 없습니다.",
    "details": null
  },
  "meta": { "requestId": "..." }
}
```

### 오류 코드

| 코드 | 설명 |
|---|---|
| `COUNTRY_NOT_FOUND` | 국가 코드를 찾을 수 없음 |
| `INDICATOR_NOT_FOUND` | 지표 ID를 찾을 수 없음 |
| `QUIZ_SESSION_NOT_FOUND` | 퀴즈 세션을 찾을 수 없음 |
| `QUIZ_SESSION_ALREADY_SUBMITTED` | 이미 제출된 퀴즈 세션 |
| `QUIZ_RESULT_NOT_FOUND` | 퀴즈 결과를 찾을 수 없음 |
| `LEADERBOARD_NOT_ELIGIBLE` | 리더보드 진입 조건 미달 |
| `INVALID_PLAYER_NAME` | 닉네임 형식 오류 |
| `VALIDATION_ERROR` | 입력값 검증 실패 |
| `INTERNAL_ERROR` | 서버 내부 오류 |

## 7. 데이터베이스 설계

Supabase PostgreSQL의 `worldvs` schema를 사용한다.

### 7.1 테이블 구조

```sql
CREATE SCHEMA IF NOT EXISTS worldvs;

-- 국가
CREATE TABLE worldvs.countries (
    code VARCHAR(2) PRIMARY KEY,
    iso3 VARCHAR(3) NOT NULL,
    name_ko VARCHAR(100) NOT NULL,
    name_en VARCHAR(100) NOT NULL,
    name_ja VARCHAR(100),
    flag_emoji VARCHAR(10),
    flag_image_url TEXT,
    capital_ko VARCHAR(100),
    capital_en VARCHAR(100),
    region VARCHAR(50) NOT NULL,
    subregion VARCHAR(50),
    latitude NUMERIC(10, 6),
    longitude NUMERIC(10, 6),
    is_active BOOLEAN DEFAULT true,
    created_at TIMESTAMPTZ DEFAULT NOW(),
    updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- 지표
CREATE TABLE worldvs.indicators (
    id VARCHAR(50) PRIMARY KEY,
    category VARCHAR(20) NOT NULL,
    name_ko VARCHAR(100) NOT NULL,
    name_en VARCHAR(100) NOT NULL,
    unit VARCHAR(20) NOT NULL,
    description_ko TEXT,
    source_name VARCHAR(100) NOT NULL,
    source_url TEXT,
    higher_is_better BOOLEAN,
    display_type VARCHAR(20) NOT NULL,
    decimal_places INT NOT NULL DEFAULT 0,
    is_mvp BOOLEAN NOT NULL DEFAULT false,
    sort_order INT NOT NULL DEFAULT 0,
    created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 국가별 지표 값
CREATE TABLE worldvs.country_indicator_values (
    id BIGSERIAL PRIMARY KEY,
    country_code VARCHAR(2) NOT NULL REFERENCES worldvs.countries(code),
    indicator_id VARCHAR(50) NOT NULL REFERENCES worldvs.indicators(id),
    value NUMERIC(20, 4),
    text_value TEXT,
    year INT,
    source_name VARCHAR(100) NOT NULL,
    note TEXT,
    created_at TIMESTAMPTZ DEFAULT NOW(),
    updated_at TIMESTAMPTZ DEFAULT NOW(),
    UNIQUE(country_code, indicator_id)
);

-- 퀴즈 문항
CREATE TABLE worldvs.quiz_questions (
    id VARCHAR(20) PRIMARY KEY,
    type VARCHAR(30) NOT NULL,
    difficulty VARCHAR(10) NOT NULL,
    category VARCHAR(20) NOT NULL,
    question_ko TEXT NOT NULL,
    question_en TEXT,
    question_ja TEXT,
    correct_option_id VARCHAR(10) NOT NULL,
    explanation_ko TEXT,
    explanation_en TEXT,
    explanation_ja TEXT,
    related_indicator_id VARCHAR(50) REFERENCES worldvs.indicators(id),
    is_active BOOLEAN DEFAULT true,
    created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 퀴즈 보기
CREATE TABLE worldvs.quiz_options (
    id BIGSERIAL PRIMARY KEY,
    question_id VARCHAR(20) NOT NULL REFERENCES worldvs.quiz_questions(id),
    option_id VARCHAR(10) NOT NULL,
    text_ko VARCHAR(200) NOT NULL,
    text_en VARCHAR(200),
    text_ja VARCHAR(200),
    sort_order INT NOT NULL DEFAULT 0,
    UNIQUE(question_id, option_id)
);

-- 퀴즈 문항-국가 연결
CREATE TABLE worldvs.quiz_question_countries (
    question_id VARCHAR(20) NOT NULL REFERENCES worldvs.quiz_questions(id),
    country_code VARCHAR(2) NOT NULL REFERENCES worldvs.countries(code),
    sort_order INT NOT NULL DEFAULT 0,
    PRIMARY KEY(question_id, country_code)
);

-- 퀴즈 세션
CREATE TABLE worldvs.quiz_sessions (
    id VARCHAR(30) PRIMARY KEY,
    mode VARCHAR(30) NOT NULL,
    category VARCHAR(20),
    difficulty VARCHAR(10),
    question_count INT NOT NULL DEFAULT 10,
    device_id_hash TEXT,
    created_at TIMESTAMPTZ DEFAULT NOW(),
    submitted_at TIMESTAMPTZ
);

-- 퀴즈 결과
CREATE TABLE worldvs.quiz_results (
    id VARCHAR(30) PRIMARY KEY,
    session_id VARCHAR(30) NOT NULL REFERENCES worldvs.quiz_sessions(id),
    score INT NOT NULL,
```

### 8.4 게이지 계산 로직

```typescript
function calculateGauge(left: number | null, right: number | null): [number, number] {
  if (left == null || right == null) return [0, 0];
  if (left <= 0 && right <= 0) return [0, 0];
  const max = Math.max(left, right);
  return [(left / max) * 100, (right / max) * 100];
}
```

### 8.5 비교 문장 생성 로직

```typescript
function generateSummary(
  leftName: string,
  rightName: string,
  leftValue: number | null,
  rightValue: number | null,
): string {
  if (leftValue == null || rightValue == null) {
    return "데이터가 부족해 비교할 수 없어요.";
  }
  if (leftValue === 0 && rightValue === 0) {
    return "두 나라 모두 값이 0입니다.";
  }

  const [biggerName, smallerName, biggerValue, smallerValue] =
    leftValue >= rightValue
      ? [leftName, rightName, leftValue, rightValue]
      : [rightName, leftName, rightValue, leftValue];

  if (smallerValue === 0) {
    return `${biggerName} 쪽 값이 더 높습니다.`;
  }

  const ratio = biggerValue / smallerValue;

  if (ratio >= 2.0) {
    return `${biggerName}이/가 ${smallerName}보다 약 ${ratio.toFixed(1)}배 높아요.`;
  }
  if (ratio >= 1.15) {
    return `${biggerName}이/가 ${smallerName}보다 약 ${Math.round((ratio - 1) * 100)}% 높아요.`;
  }
  return "두 나라가 거의 비슷해요.";
}
```

1. 클라이언트가 `POST /v1/quiz/sessions`로 세션 생성 요청
2. 백엔드에서 모드/카테고리/난이도에 맞게 DB에서 문항 필터링

6. 백엔드에서 정답 검증, 점수 산출, 결과 저장
7. 결과 ID 발급, 정답 상세와 해설 포함하여 반환

### 12.5 트렌딩 비교

`compare_views` 테이블에 조회 로그를 기록하고, 집계 쿼리로 트렌딩 TOP 10을 산출한다.

```sql
SELECT
    left_country_code,
    right_country_code,
    COUNT(*) as view_count
FROM worldvs.compare_views
WHERE created_at > NOW() - INTERVAL '7 days'
GROUP BY left_country_code, right_country_code
ORDER BY view_count DESC
LIMIT 10;
```

### 13.1 패키지 구조

```text
packages/
├─ api-contracts/
│  └─ worldvs/
│     ├─ country.schema.ts       # 국가 API 스키마
│     ├─ indicator.schema.ts     # 지표 API 스키마
│     ├─ compare.schema.ts       # 비교 API 스키마

│     └─ index.ts
├─ api-client-core/
│  ├─ http-client.ts             # Base URL, Timeout, AbortSignal
│  ├─ error.ts                   # 공통 오류 변환
│  └─ types.ts
└─ worldvs-api-client/
│  ├─ client.ts                  # createWorldVsClient()
│  ├─ countries.ts               # 국가 API 호출 함수
│  ├─ indicators.ts              # 지표 API 호출 함수
│  ├─ compare.ts                 # 비교 API 호출 함수
│  ├─ quiz.ts                    # 퀴즈 API 호출 함수
│  ├─ leaderboard.ts             # 리더보드 API 호출 함수
│  └─ index.ts
```

### 13.2 사용 예시

```typescript
import { createWorldVsClient } from '@platform/worldvs-api-client';

const client = createWorldVsClient({
  baseUrl: process.env.NEXT_PUBLIC_WORLDVS_API_URL,
});

// 비교 결과 조회
const comparison = await client.compare.getComparison('KR', 'JP');

// 퀴즈 세션 생성
const session = await client.quiz.createSession({
  mode: 'DAILY_10',
});

// 퀴즈 결과 제출
const result = await client.quiz.submitResult(session.sessionId, {
  answers: [...],
  totalDurationSeconds: 75,
});

// 리더보드 조회
const leaderboard = await client.leaderboard.getTop100();
```

API Client는 React, Next.js에 의존하지 않는 순수 TypeScript 패키지다. 향후 모바일 앱(React Native / Expo)에서도 동일한 Client를 사용한다.

## 20. AI 에이전트 개발 지시문

아래 내용을 AI 코딩 에이전트에게 전달하면 된다.

```text
pnpm workspace 모노레포로 "World VS"라는 국가 비교 웹서비스 MVP를 개발해줘.

아키텍처 원칙:
- 프론트엔드: Next.js App Router (apps/worldvs-web)
- 백엔드 API: Hono (apps/worldvs-api)
- 데이터베이스: Supabase PostgreSQL (schema: worldvs)
- 공통 패키지: packages/ 하위에 api-contracts, api-client-core, worldvs-api-client, database
- 모든 비즈니스 로직은 백엔드 API에 작성
- 프론트엔드는 데이터베이스에 직접 접근하지 않음
- SQL은 직접 작성, Parameter Binding 사용
- 입력 검증은 Zod 사용
- API 응답은 { success, data, meta } 형식

필수 페이지:
1. 홈 (/) — 오늘의 VS, 트렌딩 비교, 빠른 비교 진입
2. 비교 결과 (/compare/KR-vs-JP) — SSR, 공유 가능
3. 국가 상세 (/country/KR) — SSG, SEO
4. 퀴즈 홈 (/quiz) — 모드 선택
5. 퀴즈 진행 (/quiz/play) — 문제 풀이
6. 퀴즈 결과 (/quiz/result/:id) — SSR, 공유 가능
7. 리더보드 (/leaderboard) — TOP 100

필수 API:
- GET /v1/countries
- GET /v1/countries/:code
- GET /v1/indicators
- GET /v1/compare/:leftCode/:rightCode
- GET /v1/compare/trending
- GET /v1/compare/daily
- POST /v1/quiz/sessions
- POST /v1/quiz/sessions/:sessionId/submit
- GET /v1/quiz/results/:resultId
- GET /v1/leaderboard
- GET /v1/leaderboard/eligibility
- POST /v1/leaderboard/submit

데이터베이스:
- worldvs schema에 countries, indicators, country_indicator_values, quiz_questions, quiz_options, quiz_question_countries, quiz_sessions, quiz_results, quiz_answer_logs, leaderboard, compare_views 테이블
- 초기 데이터: 국가 30개, 지표 20개, 퀴즈 1000문항

UI:
- Tailwind CSS
- 반응형 (모바일/태블릿/데스크톱)
- 카드형 UI
- 좌우 비교 게이지 (SVG 기반)
- 국기 emoji 표시
- Material Design 느낌의 카드와 그림자

특별 요구사항:
- 비교 페이지 URL은 /compare/KR-vs-JP 형태
- 동적 OG 이미지 생성 (/api/og/compare)
- PWA manifest 설정
- 퀴즈 정답은 클라이언트에 전달하지 않음 (서버에서 채점)
- 리더보드 점수 등록은 resultId 기반으로 서버에서 재검증
- 군사 데이터는 "공개 자료 기반 추정치" 안내문 표시
- 값이 없는 항목은 "데이터 없음" 표시, 크래시 없음
- 숫자 포맷팅: 51700000 → 5,170만, 1700000000000 → 1.7조 달러
```

## 21. 향후 모바일 앱 확장

AGENTS.md 원칙에 따라, 웹서비스 출시 후 모바일 앱은 동일한 REST API를 사용한다.

```text
apps/
├─ worldvs-web/       # 웹 프론트엔드
├─ worldvs-api/       # 백엔드 API (웹과 모바일 공통)
└─ worldvs-mobile/    # 향후 React Native / Expo 앱
```

모바일 앱은 `worldvs-api-client` 패키지를 그대로 참조한다. 백엔드 API는 웹과 모바일 모두에게 동일한 공개 API를 제공하며, 플랫폼별 API를 중복 구현하지 않는다.
